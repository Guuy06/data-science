# T04 共享单车跨城市需求预测与迁移学习

《大数据技术与工程》研究生实训 · 回归预测方向 · 2026—2027 秋季学期

## 一句话结论

两城市需求曲线"形态同、水平异"（相关系数 0.9979，水平比 0.7294）。
全局 XGBoost 模型 R²=0.9090（达标线 0.80）；在目标域仅有 50~200 条样本时，
"乘性水平校正 + 样本加权联合"等权融合方案使误差下降 **22.27%~43.08%**
（达标线 10%），且全档位无负迁移。

## 复现

按编号顺序执行，**必须从 01 开始**——后一步读取前一步落盘的中间结果
（`outputs/cache/clean.csv`、`split.json`、`outputs/models/*.json`）。

```bash
cd src
python 01_data_prep.py        # ~2 s   清洗、特征工程、分层划分
python 02_eda.py              # ~6 s   图 4-1 ~ 4-5
python 03_models.py           # ~18 s  图 6-2 ~ 6-6、模型对比/消融/CV 表
python 03b_feat_ablation.py   # ~15 s  表 5-3、图 5-2
python 04_transfer.py         # ~22 s  图 6-7 ~ 6-10、迁移矩阵与增益表
python 05_interpret.py        # ~9 s   图 7-1 ~ 7-3、SHAP 重要性表
python 06_pipeline_fig.py     # ~2 s   图 6-1
```

全部跑完约 75 s，产出 20 幅图 + 20 张结果表，分别落在 `outputs/figures/`
与 `outputs/tables/`。每个脚本都可单独重跑，重跑结果一致（耗时列除外）。

### 数据定位

`src/config.py` 不写死绝对路径，按以下顺序查找 `bike.csv`，命中即用：

1. 环境变量 `BIKE_CSV`（绝对路径）
2. `bike_transfer/data/bike.csv`
3. `bike_transfer` 同级目录 `data/bike.csv`
4. 当前工作目录下的 `data/bike.csv` 或 `bike.csv`

找不到时会打印全部尝试过的路径并终止，不会静默失败。

### 可复现性

所有随机性由 `config.SEED = 42` 统一控制；下采样子种子为
`SEED + 1000*n + 重复序号`，同一环境可逐位复现。

### 说明

本包只含**实验代码**，即从原始数据到 20 幅图、20 张表的完整链路，不含报告排版脚本
与生成的 docx。报告中的全部数值均可在 `outputs/tables/*.csv` 中找到对应来源；
唯一随机器变化的是各模型的训练耗时（表 6-4 与附表 4 的"耗时(s)"列）。

## 关键实验设计

| 项 | 设定 |
|---|---|
| 源域 | city 0，训练集 3,995 条 |
| 目标域 | city 1，训练池 3,994 条（下采样 n 条）；测试集 998 条全程固定 |
| 稀疏度梯度 | n ∈ {50, 100, 200, 500, 1000, 2000, 3994} |
| 小样本重复 | n≤200 重复 8~10 次取均值±标准差 |
| 稀疏判定 | n ≤ 200（占目标域训练池 5%） |
| 主指标 | RMSE；辅助 MAE / R² / sMAPE |

### 八种迁移方案

| 代号 | 方案 | 原理 |
|---|---|---|
| T0 | 目标域独立训练 | 不迁移的对照基线 |
| T1 | 零样本直接迁移 | 源域模型直接预测 |
| T2 | 加性偏移校正 | 平移 `ȳ_t − ŷ_t` |
| T3 | 乘性水平校正 | 缩放 `k = ȳ_t / ŷ_t`（1 个参数） |
| T4 | 目标域微调 | `xgb_model` 继续 boosting |
| T5 | 样本加权联合 | 源域降权 λ=0.15，联合训练 |
| T6 | 两阶段残差校正 | 源域预测 + 目标域残差模型 |
| T7 | **本文方案** | `0.5×T3 + 0.5×T5` 等权融合 |

## 复现校验点

跑完应逐项对上（对不上说明环境或数据不一致）：

| 阶段 | 检查项 | 期望值 |
|---|---|---|
| 01 | 清洗后样本量 | 9,986 行（原始 10,000 剔除 14 条重复） |
| 01 | 训练/测试划分 | 7,989 / 1,997（city0 3,995/999，city1 3,994/998） |
| 02 | 两城曲线相关系数 / 水平比 | r=0.9979，k=0.7294 |
| 03 | 全局 XGBoost | RMSE=14.31，R²=0.9090 |
| 03b | 派生特征增益峰值 | n=100，25.09% |
| 04 | T7 增益（n=50/100/200） | 43.08% / 30.90% / 22.27% |
| 05 | SHAP 排名 | hour 第 1（mean\|SHAP\|=18.67，25.76%）；city 第 4（7.09，9.78%，定向 −14.18） |
| 全部 | 产出数量 | 20 幅图 + 20 张表 |

> 唯一不保证逐位复现的是各模型的**训练耗时**（表 6-4 与附表 4 的"耗时(s)"列）：
> 该列随 CPU 型号与当前负载变化，本机重跑即会在 2.8~3.0 s 一档浮动。
> 除该列外，所有指标均由固定种子确定，可逐位复现。

## 主要结果

### 全局模型（测试集 1,997 条）

| 模型 | RMSE | MAE | R² |
|---|---|---|---|
| B1 城市均值基线 | 47.42 | 37.82 | 0.0011 |
| B2 Ridge | 24.28 | 18.36 | 0.7380 |
| M1 RandomForest | 14.83 | 9.40 | 0.9023 |
| **M2 XGBoost 全局** | **14.31** | **9.07** | **0.9090** |
| M3 XGBoost 分层 | 14.62 | 9.45 | 0.9050 |

5 折交叉验证：R² = 0.9043 ± 0.0087

### 迁移增益（相对 T0 的误差下降 %）

| n | 50 | 100 | 200 | 500 | 1000 | 2000 |
|---|---|---|---|---|---|---|
| T1 零样本 | 10.12 | −12.16 | −26.95 | −47.83 | −56.92 | −61.35 |
| T3 乘性校正 | 40.18 | 27.41 | 17.94 | 4.72 | −1.31 | −4.70 |
| T4 微调 | 27.63 | 16.25 | 6.57 | −1.72 | −5.56 | −7.73 |
| T5 加权联合 | 39.48 | 27.15 | 19.32 | 9.40 | 4.17 | 2.03 |
| **T7 本文方案** | **43.08** | **30.90** | **22.27** | **11.31** | 5.55 | 2.80 |
